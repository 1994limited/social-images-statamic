# Social Images documentation

Social Images makes a share image (`og:image`) for each of your entries from a template you design in the Control Panel, or write in Antlers or Blade. Every template example has an Antlers and a Blade version.

## Setting up

1. [Installation](installation.md): requirements, installing, the fieldset, updating.
2. [Rendering](rendering.md): Browsershot or Cloudflare, renderers, queues and rate limits.
3. [Choosing templates](choosing-templates.md): which entries get which template, extra sizes, an entry's own image, the fallback.

## Designing

4. [The designer](designer.md): layers, fields in text, pictures, fonts, sizes, previewing and rendering.
5. [Importing and exporting](importing.md): sharing templates as JSON, and [the gallery](../gallery/README.md).
6. [Code templates](code-templates.md): Antlers or Blade views as templates.
